# Remotion Guide — Building Scenes

Prerequisite reading: `templates/remotion-vertical/.agents/skills/remotion-best-practices/`
is the vendored Remotion skill set (markup, multimedia, captions, rendering…).
Load the relevant one when doing anything beyond simple scene components.
**Never reinstall skills — they're already in the template and copied into
every project by `video new`.**

## Project shape (per project)

```
video/
  src/
    index.ts            # registerRoot — untouched
    Root.tsx            # Composition "Main", sizes from timeline data
    Video.tsx           # plays voiceover + lays scenes onto Sequence slots
    data/timeline.ts    # AUTO-GENERATED by `video sync` — never edit
    data/theme.ts       # THEME tokens — written by `video style --set`
    lib/motion.ts       # useFadeUp, usePunch, frames() helpers
    scenes/
      index.ts          # SCENES registry: { L1: Component, ... }
      DefaultScene.tsx  # fallback themed text scene
      L1Hook.tsx        # you build these, one per storyboard section
  public/audio/         # voiceover.wav + per-line wavs (copied by `tts`)
```

## The scene contract

```tsx
import React from "react";
import { AbsoluteFill } from "remotion";
import { THEME } from "../data/theme";
import { useFadeUp, usePunch, frames } from "../lib/motion";
import type { SceneProps } from "./index";

export const L1Hook: React.FC<SceneProps> = ({ line }) => {
  const { fps } = useVideoConfig();
  const enter = useFadeUp({ delay: 5 });
  const scale = usePunch({ delay: 12 });

  return (
    <AbsoluteFill style={{ /* background from THEME */ }}>
      ...
    </AbsoluteFill>
  );
};
```

- `line` = `{ id, text, audio, startFrame, durationFrames }` — the spoken
  text and your scene's exact length. **Frames inside a scene are local**: 0 =
  scene start (= line start), last frame = `durationFrames - 1`.
- Register: `export const SCENES = { L1: L1Hook };` in `scenes/index.ts`.
  Unregistered lines get `DefaultScene`, so previews never break.

## Non-negotiable rules

1. **No hardcoded colors/fonts/margins** — everything from `THEME`. That's
   what makes `video style --set` restyle the whole video instantly.
2. **No unregistered `<Audio>`** — the voiceover plays once in `Video.tsx`.
   A second `<Audio>` double-plays and drifts.
3. **Never edit `data/timeline.ts`** — regenerated by `video sync`.
   Need different timing? Change the audio, then re-sync.
4. **Stay within your Sequence** — your component only exists for
   `durationFrames`; don't build cross-scene effects with absolute frames
   unless you know what you're doing (use `useCurrentFrame()` local frames).
5. **Scene must read at a glance** — one idea per scene, per the storyboard.

## Timing math

```tsx
import { useVideoConfig, useCurrentFrame, interpolate } from "remotion";
import { frames } from "../lib/motion";

const { fps } = useVideoConfig();               // project fps (30)
const local = useCurrentFrame();                // 0 at scene start
const t = frames(THEME.motion.durations.enter, fps); // theme frames → project frames
```
Theme durations are authored at 30fps; `frames()` scales them if the project
fps differs. Count-ups, staggers and exits should all be expressed relative to
`durationFrames` so a scene fits no matter how long the line is.

## Animation helpers (`lib/motion.ts`)

- `useFadeUp({ delay?, distance?, duration? })` → `{ opacity, transform }`
  style to spread. The everyday entrance.
- `usePunch({ delay?, from?, to? })` → scale number for stamps/emphasis
  (spring with the theme's overshoot settings).
- Combine with `interpolate` for counts/swipes; use `THEME.motion.easing` via
  `Easing.bezier(...)` for custom curves.

## What belongs in a scene vs. the style

- Style decides palette/type/motion character — via `THEME`.
- Storyboard decides what this line's scene IS.
- You code the scene to both. If you need a new global visual (grain overlay,
  letterbox), put it in `Video.tsx` once, guarded by a `THEME.treatment` flag —
  not per-scene.

## Preview & iterate

```
node tools/video.mjs dev <name>     # Remotion Studio on the shared install
```
Studio's timeline lets the human scrub any line. Keep it open while building;
after each scene, jump to its frames and ask for a verdict. Remotion skill
refs: `remotion-create` (layouts), `remotion-markup` (composition structure),
`remotion-captions` (if adding captions).

## Render

`node tools/video.mjs render <name>` → `projects/<name>/output/<name>.mp4`
(`--quality preview` for half-scale speed). Render only when asked.
